# 0004 Lanes

Choice, in order: compliance when flagged, when a Critical audit risk is found, or when the visit
level is two or more levels above what is documented (unless compliance returned it); waiting on
the provider while a request is open; needs a coder when any code should change; questions to
send when only provider questions remain; otherwise ready to approve. One level too high stays
with the coder.

Follows: a compliance reviewer can confirm, keep (with a reason) or return to the coder, and can
never clear a note they flagged.
