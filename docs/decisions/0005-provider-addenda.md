# 0005 Provider questions

Choice: the message carries only a link whose token is in the URL fragment; opening it sends a
six-digit code to the provider's address on file (five attempts, ten minutes) and only then shows
the note. Questions are non-leading with neutral choices and an Other answer that needs the
provider's own words. The addendum text is built only from the provider's answers, stored as a new
note text revision, and the note is read again.
