# Shared components

Check here before writing a helper.

## backend/app/core

| Module | Provides |
|---|---|
| `config.py` | `Settings` (`DATABASE_URL` is the runtime connection and `migration_url` is `MIGRATION_DATABASE_URL` or, when unset, `DATABASE_URL`; `APP_VERSION` names the running code in each analysis; `RETENTION_DAYS` is at least `RETENTION_FLOOR_DAYS` (2557); billing settings in `BILLING_SETTINGS` read blank as unset; refuses `GEMINI_BACKEND=demo` when `APP_ENVIRONMENT` is `production`, the default; `refuse_unready_signup()` raises `SignupNotReady` when production has self sign-up on without `BAA_URL` and `TERMS_URL`, called first in the API lifespan; blank `TERMS_URL`, `BAA_URL`, `PRIVACY_URL` read as unset; `ADMIN_URL` is empty or a bare web address on another host than `APP_URL` (trailing slash dropped), `FORWARDED_ALLOW_IPS` as uvicorn reads it; `can_send_texts` is true in development and otherwise only when `SMS_TRANSPORT` is `twilio` or `sns` with every setting `TEXT_SETTINGS` names for it), `site_host(address)`, `get_settings()` |

| `statistics.py` | `wilson(successes, trials) -> Rate` (Wilson score 95% interval; `Rate.value/low/high` are None with no trials), `bootstrap_ratio(units, *, resamples=2000, seed=BOOTSTRAP_SEED) -> Rate` (ratio of summed parts to summed wholes with a percentile 95% interval from resampling the units, the unit of independence, with replacement; nearest rank, resamples with an empty denominator left out), `f1_score(precision, recall)`, `chi_square_homogeneity(first, second) -> ChiSquare \| None` (two periods over ordered levels, sparse levels pooled through `chi_square.pooled_cells`), `Z_95` |
| `model_prices.py` | `ModelPrice` (`input`, `output`: USD per million tokens, never negative), `PriceBook(prices)` (`costing(calls) -> Costing \| None`: the exact sum of every call's tokens at its model's price, rounded once to whole microdollars, with the prices used keyed by model; `None` when any call's model has no price, logging the model name once per book), `Costing` (`microusd`, `snapshot`), `MeteredCall` (`model`, `input_tokens`, `output_tokens`; `ModelReply` is one), `usd_from_microusd(amount, places=2)` (half up), `MICROUSD_PER_USD` |
| `logging.py` | `configure_logging()` (JSON lines on stdout for every process, uvicorn's access log off), `JsonFormatter` (adds the request id; exceptions as type, frames and cause types, never their message), `RequestLog` (ASGI middleware: one `bodha.access` line per request with method, route template, status, duration and request id; `X-Request-ID` in and out), `log_queue_metrics(logger, *, queued, running, at)` (CloudWatch Embedded Metric Format line, namespace `BodhaCoder`) |
